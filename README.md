# عين سين

نسخة العرض المبنية موجودة في جذر المستودع، مع مجلد assets. ملفات المشروع الأصلية مرتبة داخل project/.

للتطوير: افتح project/ ثم npm ci ثم npm run dev. للبناء: npm run build. مخرجات البناء في project/dist/؛ تُنشر محتويات هذا المجلد مع الحفاظ على مجلد assets كما هو.

خادم Cloudflare مستقل عن GitHub Pages. إعداداته ومخطط D1 داخل project/، ومعرّف قاعدة المالك مضبوط في project/wrangler.jsonc. لا يكفي رفع الواجهة لتشغيل الغرف؛ يلزم نشر الخادم وضبط عنوانه.
