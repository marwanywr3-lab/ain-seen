# عين سين | الحالة الحالية ١٢ نوفمبر ٢٠٢٦

- بنك نشط جديد من ٣٨ فئة و٧٦٠ سؤالًا، مطابق للنصوص والإجابات والنقاط في `content/source-questions-v3.json`.
- اختيار ٦ فئات؛ كل فئة فيها سؤالان لكل قيمة ٢٠٠ و٤٠٠ و٦٠٠. المجموع ٣٦ خانة، دون إعادة استخدام السؤال أو بديله في المباراة.
- الأيقونات الـ٣٨ بصيغة SVG في `public/categories-v3/`؛ أربع لوحات ١٠ + ١٠ + ١٠ + ٨ في `content/art-v3/`. أعيدت وفق مراجع المستخدم المصورة، وموسم الرياض مستند إلى شعاره المرفق.
- بطاقة الفئة: اسم وصورة على شريط وسط ملون، وعلى كل جانب عمود من ٢٠٠ و٤٠٠ و٦٠٠.
- الأونلاين يحتفظ بالمقدم والقائدين والمساعدات والخطف والفاصل. الغرف القديمة لا تستخدم قواعد v3؛ ابدأ جلسة جديدة.
- وضع أوفلاين على `#offline`: جهاز واحد وأسماء فريقين، ويمكن للمقدم اللعب. السؤال وخياراته دون تمييز الجواب الصحيح. كشف الحل متاح بعد انتهاء السؤال.
- الأوفلاين لا يستدعي API للعب. `sw.js` يحفظ الواجهة والخطوط والأسئلة والأيقونات عند أول تحميل؛ انتظر رسالة الجاهزية قبل قطع الاتصال. حذف بيانات الموقع يحتاج تجهيزًا جديدًا. إعادة تحميل الصفحة لا تحفظ مباراة جارية.
- مدة الدور ٢٠ إلى ١٢٠ ثانية؛ إيقاف الحركات محفوظ لكل جهاز. الموسيقى مؤجلة، والبرومبتات السابقة غير معتمدة.

## إضافات المحتوى

ملف المصدر لا يضم خيارات أو تلميحات. الخيارات مشتقة من أجوبة الفئة، والتلميحات من حرف البداية، مع حقول مصدر واضحة. يلزم مراجعة تحريرية لاحتمال التباس البدائل. بنية البنك والفئات قابلة للتوسعة؛ عدد الأسئلة في المباراة يبقى ٣٦ عند اختيار ٦ فئات.

## الاختبارات والرجوع

`npm run check` و`npm test` و`npm run build`. الاختبارات تشمل ١٠٠ بذرة، اكتمال ٣٦ جولة، ٧٢ سؤالًا وبديلًا فريدًا، مطابقة المصدر، واستبدال البنك والرجوع.

ترحيل `0005_catalog_v3.sql` يحفظ `pre-catalog-v3`. الرجوع عبر `scripts/rollback-catalog-v3.sql` مع نشر الواجهة والخادم من `backup/pre-38-offline-20261112`. لا تُشغّل مولد المحتوى القديم على v3. `scripts/seed.mjs` يولد ترحيل v3 فقط ولا يعيد كتابة الترحيلات التاريخية.

الاختبار الشامل المحلي تعثر بخطأ اتصال في فحص تعديل البنك، بعد تجاوز فحوص الغرف واللعب؛ لا يُعد ناجحًا بالكامل. توثيق ٣٠ فئة و٤٨٠ سؤالًا و١٨ خانة في الملف القديم هو تاريخ سابق وليس حالة النسخة الحالية.
